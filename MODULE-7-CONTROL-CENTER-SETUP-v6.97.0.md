# Module 7 — Complete AI Growth Control Center

## Access
Open `/admin/ai-growth` and select an active workspace. Only workspace owners/managers and platform administrators receive the Control Center navigation entry and API access.

## Included operating views
- CRM: new leads from the last 30 days.
- AI Employee / Inbox: conversation volume and human handoffs.
- Social: connected account inventory and token-health indicators.
- Human approvals: content, campaign and ad-optimization proposals awaiting approval.
- Execution: scheduled content, open/overdue follow-ups and failed automation jobs.
- Moderation: open Facebook/Instagram comments.
- Governance: recent workspace audit events.
- AI Usage: input/output units and estimated cost from recorded usage events.

## Data interpretation
Every metric is sourced from the selected workspace. If a source is unavailable, the dashboard displays a partial-data warning. AI usage is capped at the latest 500 records in this view; if more records exist, the dashboard marks the usage source as capped. Estimated costs are displayed without converting currencies or presenting them as billed amounts.

## Human approval boundary
The Control Center only surfaces approval queues and routes users to the relevant module. It does not automatically approve or publish content, activate ads, modify budgets, send customer commitments, or retry failed external side effects.
